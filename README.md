# Automação e Organização de Relatórios Corporativos em Python

> Projeto desenvolvido como estudo prático para automação de processos de manipulação de arquivos e extração de metadados.

## 🏢 Contexto e Objetivo
Garantir o processamento e a movimentação automática de relatórios finalizados para seus diretórios de destino, eliminando etapas manuais e estruturando um histórico de metadados dos arquivos.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Manipulação de Arquivos e Sistema:** `os`, `shutil`, `pathlib`
* **Análise de Dados:** `pandas`

## ⚙️ Funcionalidades
1. **Filtragem Dinâmica:** Identificação automática de arquivos contendo o sufixo `_processado`.
2. **Movimentação Segura:** Transferência dos relatórios para a pasta de destino com tratamento para garantia da existência do diretório.
3. **Mapeamento de Metadados:** Estruturação de dados contendo data de modificação e tamanho de cada arquivo.
